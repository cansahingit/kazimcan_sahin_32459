
# Quantitative trading model (DONT FORGET TO INSPECT FINAL.PDF)
**DSA 210 — Introduction to Data Science · Sabancı University · Spring 2026**
**Author: Kazimcan Sahin**

This project asks a simple question: *can machine learning predict whether a stock will go up or down tomorrow?* The answer, it turns out, is no — and understanding why leads to something more interesting.

The project runs in two phases. In Phase 4, I applied standard ML models (Linear Regression, Logistic Regression, KNN, Decision Trees) to 10 individual U.S. stocks and found that all of them fail, producing near-zero or negative R² scores. Rather than stopping there, I used that failure as a starting point: I read 7 academic papers from quantitative finance — Dow Award winners and peer-reviewed research — and tried to implement their ideas from scratch. The result is Phase 5: an amateur quantitative trading model that rotates between 11 sector ETFs every month based on momentum, volatility, and correlation. That works considerably better.

---

## Key Findings

- Every linear model (OLS, Ridge, Lasso) produced **negative R²** across all 10 stocks. This is not a bug — it is consistent with the Efficient Market Hypothesis (Fama, 1970): past prices contain no reliable signal about tomorrow's return.
- Logistic Regression AUC-ROC ranged from **0.47 to 0.64**. JPM and GOOGL showed the highest directional predictability; JNJ and CAT were effectively random.
- KNN performed best at **k=15–20** — essentially averaging over many neighbors, which is the same as predicting the mean. No real signal.
- Decision Trees optimal at **depth 1–2**. Deeper trees memorized training noise completely (MSFT unconstrained: R²=−1.63).
- After reading 7 quantitative finance papers and implementing their ideas, the FAA sector rotation model achieved **Sharpe 0.537 vs SPY's 0.481**, with all four active models generating positive alpha.
- EAA + MA Filter reduced maximum drawdown from **−50.8% (SPY) to −15.4%** by rotating into long-term bonds during bear markets.

The complete analysis is in `dsa210_final_report_final.pdf`.

## The 7 Papers Behind Phase 5

| Paper | What I took from it |
|-------|---------------------|
| Zarattini & Antonacci (2025) — *A Century of Profitable Industry Trends* | Sector ETFs beat individual stocks at monthly frequency |
| Wilcox, Zarattini & Pagani (2025) — *Does Trend Following Still Work on Stocks?* | The failure of daily prediction is a frequency problem, not a model problem |
| Keller & van Putten (2012) — *Flexible Asset Allocation (FAA)* | Rank assets by Return + Volatility + Correlation, not just momentum |
| Keller & Butler (2014) — *Elastic Asset Allocation (EAA)* | Geometric weighting + automatic crash protection when momentum turns negative |
| Giordano (2018) — *Ranked Asset Allocation Model* | Cross-sectional ranking beats absolute prediction; antifragility via safe havens |
| Gayed (2016) — *Leverage for the Long Run* | When SPY drops below its 200-day MA, rotate to bonds — volatility regime matters |
| Moskowitz & Grinblatt (1999) — *Do Industries Explain Momentum?* | Industry momentum is stronger and more persistent than single-stock momentum |

## How to Run — Step by Step

### What you need

- **Python 3.9 or higher** — [download here](https://www.python.org/downloads/)
- **Visual Studio Code** — [download here](https://code.visualstudio.com/)
- **Git** — [download here](https://git-scm.com/)

---

### Step 1 — Install VS Code Extensions

Open VS Code, go to the Extensions panel (Ctrl+Shift+X on Windows, Cmd+Shift+X on Mac), and install:

- **Python** (by Microsoft) — required
- **Pylance** (by Microsoft) — recommended for autocomplete

---

### Step 2 — Clone the Repository

Open VS Code, then open the integrated terminal:
`View → Terminal` (or Ctrl+` on Windows, Cmd+` on Mac)

```bash
git clone https://github.com/YOUR_USERNAME/DSA210_Project.git
cd DSA210_Project
```

---

### Step 3 — Create a Virtual Environment

Still in the terminal:

```bash
# macOS / Linux
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

You should see `(venv)` appear at the start of your terminal prompt. This means the virtual environment is active.

---

### Step 4 — Install Dependencies

```bash
pip install -r requirements.txt
```

This installs everything needed: numpy, pandas, matplotlib, seaborn, scipy, scikit-learn, and yfinance. It takes about 1–2 minutes.

---

### Step 5 — Select the Python Interpreter in VS Code

Press `Ctrl+Shift+P` (Windows) or `Cmd+Shift+P` (Mac), type:

```
Python: Select Interpreter
```

Choose the one that shows `venv` in its path (e.g. `./venv/bin/python`).

---

### Step 6 — Run Phase 4

```bash
python phase4_sector_ml.py
```

This will:
- Download daily stock data from Yahoo Finance (2018–2024)
- Compute 16 technical indicators per stock
- Run Linear Regression, Logistic Regression, KNN, and Decision Tree with TimeSeriesSplit cross-validation
- Print results to the terminal
- Save 5 figures + a summary CSV to `phase4_outputs/`

Expected runtime: **5–15 minutes** depending on your internet speed.

---

### Step 7 — Run Phase 5

```bash
python phase5.py
```

This will:
- Download monthly ETF data from Yahoo Finance (2005–2024)
- Compute FAA features (momentum, volatility, correlation) for each sector
- Run FAA, EAA, FAA+MA, and EAA+MA models
- Print a full performance summary to the terminal
- Save 5 figures + 5 CSV files to `phase5_outputs/`

Expected runtime: **1–3 minutes**.

> **No internet?** Phase 5 automatically falls back to a calibrated simulation if Yahoo Finance is unavailable. You will see `[SIMULATED DATA]` in the terminal output instead of `[REAL DATA]`.

---

### Troubleshooting

| Problem | Fix |
|---------|-----|
| `ModuleNotFoundError: No module named 'yfinance'` | Run `pip install -r requirements.txt` again and make sure `(venv)` is active |
| `python` command not found | Try `python3` instead of `python` |
| VS Code does not show venv as interpreter | Close and reopen VS Code after creating the venv |
| yfinance download fails / times out | Re-run the script — Yahoo Finance occasionally rate-limits requests |

## Methods at a Glance

| Phase | Script | Key Techniques |
|-------|--------|----------------|
| 4 — Individual Stock ML | `phase4_sector_ml.py` | 16 technical indicators, KNN Imputation, TimeSeriesSplit CV, Linear/Logistic Regression, KNN, Decision Tree |
| 5 — Sector Rotation | `phase5.py` | FAA rank-based allocation, EAA geometric weights, SPY 200-day MA regime filter, monthly rebalancing |

**Why TimeSeriesSplit?** A standard random train/test split allows future data to contaminate training. TimeSeriesSplit enforces chronological order — always train on the past, test on the future.

**Why sector ETFs instead of individual stocks?** Moskowitz and Grinblatt (1999) show that industry-level momentum is stronger than individual stock momentum. Individual stock daily returns are noise; sector monthly trends are signal.
